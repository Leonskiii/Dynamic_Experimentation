# Software Experiments – Indentation & Dynamic Indentation

This repository contains the code for a set of N-of-1 trials on source code
indentation, conducted as part of a Bachelor's thesis at the University of
Duisburg-Essen.

## Credits

The experiment framework used in this project was developed by
[Stefan Hanenberg](https://sites.google.com/site/stefanhanenberg/) and is
originally available at
[shanenbe/N-of-1-Experimentation](https://github.com/shanenbe/N-of-1-Experimentation).
It has been integrated directly into this repository (see `N_of_1_Experiments/`),
so no separate clone is required to run the experiments.

## Running locally

Clone the current repository:

```
git clone https://github.com/Leonskiii/Dynamic_Experimentation.git
```

That's it — the N-of-1 framework is already included, so no further setup is needed.

## Structure of the Repository

The `Indentation_Main_Experiment` and `Dynamic_Indentation_Main_Experiment`
directories include the code for the main experiments.

The directories `Baseline_Indentation_Experiment`,
`Chained_Conditions_Preliminary_Experiment`, and
`Dynamic_Indentation_Preliminary` include the code for the preliminary
experiments.
